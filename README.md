# PriceAction ML BR - Expert Advisor para MetaTrader 5

**🤖 EA Brasileiro com Machine Learning para Trading Automatizado**

> Expert Advisor avançado que combina análise técnica de Price Action com algoritmos de Machine Learning e análise fundamental, desenvolvido especialmente para a comunidade brasileira de traders.

## 🎯 **Características Principais:**

- **Machine Learning Integrado** - 5 estratégias de IA diferentes
- **12 Padrões de Candlestick** - Detecção automática com validação
- **Gestão de Risco Inteligente** - 3 tipos de gestão configuráveis
- **Análise Fundamental** - Filtro de notícias e eventos econômicos
- **Totalmente em Português** - Interface e documentação traduzidas

## 🚀 **Comece a Usar em 3 Passos:**

1. **Baixe** os arquivos do EA
2. **Copie** para a pasta MQL5 do seu MetaTrader 5
3. **Compile** e arraste para o gráfico
